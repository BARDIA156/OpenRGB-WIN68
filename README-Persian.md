# پلاگین OpenRGB برای AULA WIN68

![لوگوی پروژه](assets/Logo.png)

کیبورد AULA WIN68 HE خود را به OpenRGB متصل کنید و نورپردازی آن را با سایر تجهیزات RGB خود هماهنگ کنید.

> [!IMPORTANT]
> این پروژه هنوز جدید است و ممکن است دارای اشکالاتی باشد. اگر با مشکلی مواجه شدید، لطفاً آن را در بخش [Issues](https://github.com/BARDIA156/OpenRGB-WIN68/issues) گزارش کنید.

## ✨ ویژگی‌ها

- پشتیبانی از جلوه‌های نورپردازی داخلی کیبورد

- امکان انتخاب رنگ برای هر کلید
- سازگار با **OpenRGBEffectsPlugin**
- دارای کنترل روشنایی و سرعت
- قابلیت کار هم‌زمان با سایر دستگاه‌های پشتیبانی‌شده توسط **OpenRGB**
- نمایش چیدمان دقیق کلیدها در **Toggle LED View**
- نصب آسان به‌صورت Drag-and-Drop
- شامل کد منبع و نسخهٔ کامپایل‌شده

## 🪛 نصب

1. آخرین نسخه را از صفحهٔ [Releases](https://github.com/BARDIA156/OpenRGB-WIN68/releases) دانلود کنید.
2. فایل دانلودشده را استخراج کنید.
3. فایل‌های پلاگین استخراج‌شده را به پوشهٔ `plugins` برنامهٔ OpenRGB منتقل کنید. این پوشه معمولاً در مسیر زیر قرار دارد:

   `C:\Program Files\OpenRGB\plugins`

اگر پوشهٔ OpenRGB را پیدا نمی‌کنید، روی میانبر OpenRGB راست‌کلیک کرده و گزینهٔ **Open file location** را انتخاب کنید.

پس از نصب پلاگین، OpenRGB را دوباره اجرا کنید.

## 🔧 ساخت از سورس با GitHub Actions

نسخه‌های کامپایل‌شده در صفحهٔ [Releases](https://github.com/BARDIA156/OpenRGB-WIN68/releases) در دسترس هستند. اگر می‌خواهید پلاگین را خودتان بسازید، می‌توانید از GitHub Actions در Fork شخصی خود استفاده کنید:

1. از این مخزن در حساب GitHub خود **Fork** بگیرید.
2. در Fork خود، تب **Actions** را باز کنید و در صورت نمایش درخواست، Workflowها را فعال کنید.
3. Workflow مربوط به ساخت را از نوار کناری سمت چپ انتخاب کنید.
4. روی **Run workflow** کلیک کنید، شاخهٔ موردنظر را انتخاب کرده و اجرا را تأیید کنید.

5. پس از پایان موفقیت‌آمیز ساخت، اجرای Workflow را باز کرده و پلاگین را از بخش **Artifacts** دانلود کنید.

فایل Workflow باید در Fork شما در مسیر `.github/workflows/build-plugin.yml` قرار داشته باشد و از اجرای دستی با استفاده از `workflow_dispatch` پشتیبانی کند.

## 🔧 ساخت محلی

راهنمای ساخت محلی هنوز آماده نشده است. این پروژه در ساخت GitHub Actions خود از سورس OpenRGB با شاخهٔ `release_1.0` و Qt 6.8.3 استفاده می‌کند. ممکن است دستورالعمل‌های بیشتری برای ساخت محلی در آینده اضافه شود.
