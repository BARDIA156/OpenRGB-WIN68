# OpenRGB AULA WIN68 Plugin
Connect Your AULA WIN68 HE To **OpenRGB** And Sync it with your Other RGB Devices.
> [!IMPORTANT]
> This Project is Very New and Has Many Bugs. If You Found Any Bugs, Please Report it.

## ✨ Features
- All The WebDriver Effects

- Per-Key Color Slection
- Compatible With "**OpenRGBEffectsPlugin**"
- Brightness And Speed Bar
- Easy to Use
- Compatible With Other Hardware in **OpenRGB**
- Source Code (If You Wana Make It Yourself) and Compiled Version of Project.
- Drag And Drop Installation
- Accurate Key-mapping In "**Toggle LED View**" In **OpenRGB** For Better Per-key Experience.

# 🪛 Installation 
1. Download the Latest **[Release](https://github.com/BARDIA156/OpenRGB-WIN68/releases)
2. Extract The Downloaded File
3. Move The Extracted Files to `C:\Program Files\OpenRGB\plugins`

If You Couldn't find Your OpenRGB Folder, Just Right Click on OpenRGB Shortcut and Select **"Open File Location"**
