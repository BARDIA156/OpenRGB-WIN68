# OpenRGB AULA WIN68 Plugin
Connect Your AULA WIN68 HE To **OpenRGB** And Sync it with your Other RGB Devices.
> [!IMPORTANT]
> This Project is Very New and Has Many Bugs. If You Found Any Bugs, Please Report it.

## ✨ Features
- All The WebDriver Effects

- Per-Key Color Slection
- Compatible With "**OpenRGBEffectsPlugin**"
- Brightness And Speed Bar
- Easy to Use
- Compatible With Other Hardware in **OpenRGB**
- Source Code (If You Wana Make It Yourself) and Compiled Version of Project.
- Drag And Drop Installation
- Accurate Key-mapping In "**Toggle LED View**" In **OpenRGB** For Better Per-key Experience.

# 🪛 Installation 
1. Download the Latest Project **[Release](https://github.com/BARDIA156/OpenRGB-WIN68/releases)**

2. Extract The Downloaded File
3. Move The Extracted Files to `C:\Program Files\OpenRGB\plugins`

If You Couldn't find Your OpenRGB Folder, Just Right Click on OpenRGB Shortcut and Select **"Open File Location"**

# 🔧 Building from Source ( Github ) 
You Need to Have a **_Github Account_** to Continue this Guide.
> [!WARNING]
> If You Make any Wrong Mistake, the Project Doesn't Build Correctly. Please Do This If You Know What are You Doing Because This Step is Very **_Complicated_**.

For Better Explain, Please Read This **[Official Guide](https://docs.github.com/en/repositories/creating-and-managing-repositories/quickstart-for-repositories?tool=webui#create-a-repository)**

After Reading This Guide and Made Your Repository, You Can Continue to Next Step.

1. Download the Project by Clicking This Link --> **[Source](https://github.com/BARDIA156/OpenRGB-WIN68/archive/refs/heads/main.zip)**

2. Extract the Downloaded and Open It.
3. There You Will See Many Folders and Files, Just Select All of them.
4. Using a ZIP Software like `7zip` or `WinRAR`, Make a New .zip File and Name it Exactly `plugin-source-new.zip` (Just one ".zip" not two like ".zip.zip", Double Check it)
5. Do NOT! Delete the Source Even After Making a zip of it, we Still Need `build-plugin.yml` Inside The root Folder.
6. Open Your New Repository and Click "**Add File**" and then "**Create new file**".
7. Name Your File Exactly `.github/workflows/build-plugin.yml`
8. Open Our `build-plugin.yml` That Was Inside Project Source and Copy All the Text to the New File we are making in Github. Or You Can **[Click Me](https://github.com/BARDIA156/OpenRGB-WIN68/blob/main/build-plugin.yml)** to Directly go to The File And Copying it.
9. After All the Text Has Been Moved, Click on The Button Named "Commit changes…".
10. Go To The "Code" Section of Your Repository.
11. Click On "**Add file**" and "**Upload files**".
12. Drag and Drop Our New `plugin-source-new.zip` that We Made Before, After Upload Complete, click on "Commit changes" Down the Page.
13. Go to the "Actions" Section and There You Will See a New Workflow That Has a Spinning Icon Next to it, Click on it.
14. Wait about 1 ⁓ 2 Minutes to Finish the Compiling. If it Take long or didn't see any changes, just refresh your browser.
15. If You Done the Steps Correctly and I Explained it Correctly, You Will See a Check Mark Next to The File.
16. By Scrolling Down on That Page, in the "Artifacts" Section There Will Be a File Named "OpenRGB-WIN68-1.0.0-OpenRGB-1.0-windows-x64"

Congratulation, You Just Compiled Our Project by Yourself👍 and Successfully Have a .dll in the New Downloaded File.
